# Задание 47. Модель оттока клиентов в Docker

В образ включён обученный пайплайн из `task_46.ipynb`. Он заполняет пропуски, кодирует категориальные признаки и прогнозирует отток клиентов.

```sh
docker build -t telco-churn .
docker run --rm -i telco-churn < example.csv
```

Контейнер читает CSV со стандартного ввода и возвращает CSV с прогнозами. В столбце `churn` единица означает прогноз оттока, в `churn_probability` указана оценка вероятности оттока. Структура входных данных показана в `example.csv`.
